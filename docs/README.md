# Documentation

📚 This is the reader-facing documentation for `ose-primer`, a reusable polyglot Nx starter. It helps you decide what to keep, what to learn from, and how to get a first demo running before you reshape the template for your own product.

## Pick the help you need

| If you want to…                               | Start here                                                             |
| --------------------------------------------- | ---------------------------------------------------------------------- |
| See the starter working from a fresh checkout | [Run the Next.js demo](./tutorials/getting-started-with-ose-primer.md) |
| Learn through a guided outcome                | [Tutorials](./tutorials/README.md)                                     |
| Solve a specific setup or development problem | [How-to guides](./how-to/README.md)                                    |
| Look up commands, structure, or contracts     | [Reference](./reference/README.md)                                     |
| Understand the choices behind the workspace   | [Explanation](./explanation/README.md)                                 |

## How this documentation is organized

The repository uses the [Diátaxis framework](https://diataxis.fr/) so each document has a clear job:

- **Tutorials** build confidence through a complete, learning-oriented path.
- **How-to guides** help you complete a focused task when you already know your goal.
- **Reference** records facts you need to look up accurately.
- **Explanation** connects technical decisions to the problem they solve.

## A note on scope

`ose-primer` is a template, while [ose-public](https://github.com/wahidyankf/ose-public) is the public OSE platform. Use this documentation to adapt a starter; use `ose-public` when you want product context for the platform itself.

External contributions to this repository are closed. You may fork the MIT-licensed template and make it your own; see [Working with ose-primer](../CONTRIBUTING.md) for the boundary and safety guidance.
